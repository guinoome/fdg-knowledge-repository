# FSIS-1300 — Security Architecture Master Index

FSIS is a cross-cutting protection layer.

```text
Layer 0 — Owner Authority
Layer 1 — FDG Governance
Layer 2 — Identity & Trust
Layer 3 — Authorization
Layer 4 — Knowledge Classification
Layer 5 — Work Package Context
Layer 6 — Tool / System Permissions
Layer 7 — Audit / Monitoring
Layer 8 — Security Intelligence
```

No single layer should be assumed to provide complete security.

*Note added 2026-08-06: this is a fourth layer model found in the repository, alongside the three already cross-referenced in the Master Index (NEX-STD-026, NEX-STD-036, and the 5-layer Candidate). Unlike those three, this one is explicitly scoped to security architecture specifically, not the whole ecosystem — noted here rather than added to that cross-reference, since it answers a narrower question than those three do.*
