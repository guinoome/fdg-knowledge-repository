# FSIS-1400 — FDG Security Integration Master Index

FSIS integrates across the FDG Ecosystem without owning other domains.

```text
FDG CORE
  │
  ├── FEIS
  ├── FBIS
  ├── FBPOIS
  ├── FWFIS
  └── Future Intelligence Systems
          │
          ▼
         FSIS
```

FSIS governs the security boundary, while each intelligence system retains domain authority.

The preferred integration path is:

```text
Domain System
→ Security Classification
→ Authorization
→ Controlled Context
→ Collaborator
→ Validated Output
→ Domain Repository
```
