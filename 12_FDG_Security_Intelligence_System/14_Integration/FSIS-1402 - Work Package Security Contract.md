# FSIS-1402 — Work Package Security Contract

Every security-sensitive collaboration should have a bounded contract:

```text
WP-ID:
Objective:
Owner:
Collaborator:
Required Knowledge:
Knowledge Classification:
Allowed Repositories:
Allowed Tools:
Allowed Actions:
Expected Output:
Security Restrictions:
Export Permission:
Review Requirement:
Expiry:
```

This contract connects FDG's focused work-package methodology to FSIS security governance.
