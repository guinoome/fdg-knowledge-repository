# FSIS-1401 — FDG Knowledge Repository Security Integration

The FDG Knowledge Repository remains organizational memory.

FSIS should attach security metadata and governance to repository knowledge rather than duplicate the repository.

Repository security should eventually support:

- classification;
- ownership;
- access policy;
- export policy;
- modification policy;
- audit requirements;
- lineage;
- retention;
- review status.

Do not expose the entire repository to an external collaborator merely because a tool can index it.
