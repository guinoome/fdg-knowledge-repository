# FSIS-0601 — AI Collaborator Security Standard

Each AI assignment should define:

```text
Task
Required Context
Authorized Knowledge
Allowed Tools
Allowed Actions
Expected Output
Security Restrictions
Review Requirement
```

Standard instruction:

> Operate only within the assigned work package and explicitly provided context. Do not request, retrieve, infer, reconstruct, or expose information outside the authorized scope.

Do not provide complete-vault context merely for convenience.
