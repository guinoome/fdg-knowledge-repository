# FSIS-0600 — AI Security Master Index

AI collaborators are external intelligence/execution resources unless explicitly placed inside the FDG trust boundary.

FSIS governs:

- approved AI use;
- context boundaries;
- data exposure;
- tool permissions;
- output handling;
- auditability;
- revocation.

AI capability does not imply access to FDG CORE.
