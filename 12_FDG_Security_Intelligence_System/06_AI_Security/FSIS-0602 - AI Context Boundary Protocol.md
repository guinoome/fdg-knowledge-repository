# FSIS-0602 — AI Context Boundary Protocol

## Context construction

```text
Objective
↓
Minimum required inputs
↓
Relevant standards
↓
Relevant prior decisions
↓
Acceptance criteria
↓
Security restrictions
```

Exclude unrelated architecture, strategy, credentials, and restricted knowledge.

## Output handling

AI output is not automatically FDG truth.

It must be reviewed according to the relevant domain's governance and then incorporated into the authoritative repository when approved.
