# FSIS-0400 — Knowledge Security Master Index

Knowledge security protects FDG's organizational memory and intellectual assets.

The repository remains the authoritative memory. FSIS adds classification, access, disclosure, and security metadata.

Core controls:

- classification;
- compartmentalization;
- controlled disclosure;
- access authorization;
- export control;
- retention;
- lineage;
- review.
