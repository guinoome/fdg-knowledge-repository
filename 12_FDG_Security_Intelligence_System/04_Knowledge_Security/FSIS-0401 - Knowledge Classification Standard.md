# FSIS-0401 — Knowledge Classification Standard

## Classification levels

### Public
Safe for external disclosure.

### Internal
Approved FDG operational knowledge.

### Confidential
Disclosure could materially affect FDG operations, strategy, projects, finances, or intellectual property.

### Restricted
Highly sensitive knowledge requiring explicit authorization.

### FDG CORE
Highest-security organizational intelligence.

Examples of CORE material include master architecture, governance constitution, sensitive security architecture, owner-level strategy, secrets, and information that could materially enable reconstruction of the FDG Ecosystem.

## Required metadata

```text
Classification
Owner
Domain
Authorized Roles
Authorized Systems
Authorized Collaborators
Retention
Export Permission
Modification Permission
Audit Requirement
```
