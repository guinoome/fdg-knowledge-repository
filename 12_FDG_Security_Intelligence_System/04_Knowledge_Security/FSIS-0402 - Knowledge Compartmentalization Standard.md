# FSIS-0402 — Knowledge Compartmentalization Standard

Separate knowledge by domain, sensitivity, task, and need.

A collaborator working on one system should not automatically receive:

- the entire Obsidian vault;
- unrelated intelligence-system roadmaps;
- owner strategy;
- all historical decisions;
- all source code;
- all security architecture.

Preferred context:

```text
Work Package
+
Required Context
+
Relevant Standards
+
Required Inputs
+
Acceptance Criteria
```

Compartmentalization reduces blast radius when an account, document, collaborator, or integration is compromised.
