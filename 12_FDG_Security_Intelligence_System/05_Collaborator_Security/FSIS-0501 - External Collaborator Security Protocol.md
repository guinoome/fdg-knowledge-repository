# FSIS-0501 — External Collaborator Security Protocol

Before sharing information externally:

1. Define the work package.
2. Identify minimum required knowledge.
3. Classify each knowledge item.
4. Identify the collaborator.
5. Verify authorization.
6. Prepare a bounded context package.
7. Specify allowed tools/actions.
8. Execute.
9. Review the output.
10. Store approved knowledge in FDG.
11. Revoke temporary access where applicable.

Foundational rule:

> An external collaborator may receive sufficient information to perform an assigned task but shall not automatically receive sufficient information to understand, reproduce, or reconstruct the complete FDG Ecosystem.
