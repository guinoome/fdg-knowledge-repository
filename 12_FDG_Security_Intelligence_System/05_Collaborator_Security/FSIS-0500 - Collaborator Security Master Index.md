# FSIS-0500 — Collaborator Security Master Index

FSIS governs human and external collaborators.

### Trust levels

```text
Level 0 — Public
Level 1 — Approved Research Collaborator
Level 2 — Domain Specialist
Level 3 — Engineering Collaborator
Level 4 — FDG Core Collaborator
Level 5 — Owner Authorization
```

Trust is scoped. A higher level is not automatically required for every task.

Each assignment should specify the collaborator, task, required context, allowed tools, allowed actions, classification ceiling, and review requirements.
