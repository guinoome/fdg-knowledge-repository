# FSIS-1200 — Security Standards Master Index

FSIS standards should define repeatable security behavior.

Initial standard families:

- identity;
- access;
- knowledge classification;
- collaborator security;
- AI security;
- IP protection;
- cybersecurity;
- audit;
- incident response;
- integration.

External laws, regulations, contractual requirements, and recognized standards should be incorporated when applicable and verified before being treated as authoritative.
