# FSIS-1100 — Incident Response Master Index

Incident response should follow:

```text
Detect
→ Triage
→ Contain
→ Preserve Evidence
→ Investigate
→ Recover
→ Validate
→ Record Lessons
→ Improve Controls
```

Examples include unauthorized access, credential compromise, data exposure, malicious software, repository compromise, or suspicious collaborator activity.

Incident response must preserve evidence and avoid destroying useful information during containment.
