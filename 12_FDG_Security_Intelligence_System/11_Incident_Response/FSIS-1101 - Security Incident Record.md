# FSIS-1101 — Security Incident Record

Use this template for material incidents.

```text
Incident ID:
Date / Time:
Reporter:
Affected System:
Affected Knowledge:
Classification:
Initial Detection:
Observed Facts:
Immediate Actions:
Containment:
Evidence:
Impact:
Root Cause:
Corrective Actions:
Owner:
Status:
Review Date:
Lessons Learned:
Related Decisions:
```

Clearly distinguish observed facts from assumptions and conclusions.
