# FSIS-0300 — Access Control Master Index

Access control determines what an authenticated identity may access and do.

Use:

```text
Identity
+ Role
+ Task
+ Knowledge Classification
+ System
+ Time
+ Action
= Authorization Decision
```

Default state:

> **No access unless authorized.**

Controls must be enforced at the system/service boundary where technically possible, not merely by hiding interface elements.
