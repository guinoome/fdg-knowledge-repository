# FSIS-0302 — Access Review Procedure

Review access when:

- a work package changes;
- a collaborator changes role;
- a project closes;
- a security classification changes;
- a system changes;
- access expires;
- an incident occurs.

Review:

1. identity;
2. current role;
3. actual access;
4. required access;
5. unused permissions;
6. export capability;
7. modification authority;
8. expiry.

Remove unnecessary permissions.
