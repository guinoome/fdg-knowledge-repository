# FSIS-0301 — Least Privilege Standard

Grant only the minimum knowledge, tool access, repository access, and operational authority required to complete the work package.

Prefer:

```text
Specific task
→ specific context
→ specific repository
→ specific action
→ specific duration
```

Avoid:

```text
General task
→ entire vault
→ unrestricted tools
→ permanent access
```

Temporary access should be revoked when no longer required.
