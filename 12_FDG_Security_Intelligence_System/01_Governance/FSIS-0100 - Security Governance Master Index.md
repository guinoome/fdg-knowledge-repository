# FSIS-0100 — Security Governance Master Index

## Purpose

Defines the governance authority, responsibilities, decision rights, and lifecycle rules for FSIS.

## Governance hierarchy

```text
FDG Governance
   ↓
FSIS Governance
   ↓
Security Standards
   ↓
Security Procedures
   ↓
Technical Controls
   ↓
Audit / Review
```

## Principles

1. Security requirements are explicit.
2. Access is granted intentionally.
3. Least privilege is the default.
4. Security decisions are traceable.
5. FDG CORE receives the highest protection.
6. Security controls must support useful work.
7. Technical automation follows validated governance.

## Decision authority

The FDG owner retains ultimate authority over FDG CORE, ecosystem-wide security boundaries, and exceptional access.

Domain owners manage security requirements within their systems subject to FDG governance.

## Lifecycle

```text
Define → Approve → Implement → Test → Operate → Review → Improve → Retire
```
