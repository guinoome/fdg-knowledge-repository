# FSIS-0101 — FDG Security Constitution

## Constitutional principles

### 1. FDG is the protected organizational asset

The security objective is protection of FDG knowledge, architecture, organizational memory, systems, and intellectual property.

### 2. Collaboration is permitted

Security shall not unnecessarily obstruct legitimate work.

### 3. Access is scoped

Authorization applies to a defined person, system, task, knowledge set, and permitted action.

### 4. No implicit full trust

Useful collaboration does not imply unrestricted trust.

### 5. Knowledge is compartmentalized

Compromise of one work package should not automatically expose unrelated domains.

### 6. FDG CORE is highest security

CORE access requires explicit authorization.

### 7. Organizational memory remains FDG-controlled

Approved knowledge returns to the FDG Knowledge Repository.

### 8. Security must be auditable

Material access and security decisions should be traceable where technically and legally appropriate.

### 9. External systems are controlled boundaries

External AI, software, services, and collaborators are not assumed to be inside the FDG trust boundary.

### 10. Capability without disclosure

A collaborator should receive enough information to perform the work, not enough information to reconstruct the whole ecosystem.
