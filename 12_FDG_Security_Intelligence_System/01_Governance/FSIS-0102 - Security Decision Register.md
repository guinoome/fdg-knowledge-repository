# FSIS-0102 — Security Decision Register

Use this register for material FSIS decisions.

| Field | Requirement |
|---|---|
| Decision ID | Unique identifier |
| Date | Decision date |
| Decision Owner | Authorized decision maker |
| Scope | Affected system/domain |
| Problem | Security problem |
| Options | Considered approaches |
| Decision | Approved approach |
| Rationale | Evidence-based reason |
| Security Impact | Exposure/control impact |
| Reversal Conditions | When decision should be revisited |
| Related Documents | Obsidian links |

Do not silently replace an approved security decision. Record superseding decisions explicitly.
