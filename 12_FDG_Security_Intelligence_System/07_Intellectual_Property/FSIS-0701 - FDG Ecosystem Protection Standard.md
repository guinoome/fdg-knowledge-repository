# FSIS-0701 — FDG Ecosystem Protection Standard

The FDG Ecosystem should not be exported as one unrestricted knowledge package.

Protect against:

- bulk repository exposure;
- unnecessary context sharing;
- unrestricted source-code access;
- uncontrolled exports;
- credential disclosure;
- strategic-document disclosure;
- uncontrolled synchronization to external services.

The organizational objective is:

> **Useful collaboration without surrendering control of organizational intelligence.**
