# FSIS-1000 — Security Intelligence Master Index

Security intelligence converts security evidence into actionable organizational knowledge.

Potential intelligence:

- abnormal access;
- repeated unauthorized requests;
- privilege escalation;
- unusual data movement;
- collaborator anomalies;
- repository anomalies;
- incidents;
- emerging threats;
- control failures.

The objective is detection and informed response, not surveillance for its own sake.
