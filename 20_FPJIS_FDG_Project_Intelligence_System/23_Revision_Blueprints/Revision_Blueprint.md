## Requirement and Implementation Impact Extension — 2026-10-10

A material revision should identify impact on:

- requirement IDs
- acceptance criteria
- users/roles
- screens
- workflows/state machines
- business rules
- data/database
- APIs/events
- security/privacy
- NFRs
- offline/sync
- tests
- implementation packages
- released versions
- operational procedures
- reusable blueprints

Revision status should distinguish:

~~~text
BLUEPRINT_ONLY
IMPLEMENTATION_REQUIRED
MIGRATION_REQUIRED
RETEST_REQUIRED
RELEASE_REQUIRED
OPERATIONAL_CHANGE_REQUIRED
~~~

If an accepted module is affected, the module may be reopened through a new revision while preserving previous acceptance evidence.
