## Rule Governance and Traceability Extension — 2026-10-10

For material rules additionally define:

- rule ID;
- authority/source;
- effective date;
- expiry/supersession if applicable;
- input types/units;
- deterministic formula/logic where applicable;
- precedence when rules conflict;
- missing-input behavior;
- exception authority;
- affected requirements/workflows/data;
- test IDs;
- evidence/provenance;
- revision history.

A rule must not silently change because UI wording, a model response, or an external reference changes.

External regulatory rules should reference the responsible legal/regulatory authority rather than becoming an independent FPJIS legal catalogue.

Rule changes after implementation require impact analysis under:
