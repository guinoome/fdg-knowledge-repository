# Entitlement Blueprint

Entitlement is the standard mechanism for free/paid access.

Example:

FREE
- dashboard access
- basic feature
- limited records
- contact admin

PREMIUM
- everything free
- advanced features
- higher limits
- premium workflows

Payment does not directly unlock UI.

Payment verification changes entitlement state.

Define:
- entitlement ID
- capability
- user/role
- plan
- limits
- conditions
- activation
- expiration
- suspension
- grace period
- audit trail
