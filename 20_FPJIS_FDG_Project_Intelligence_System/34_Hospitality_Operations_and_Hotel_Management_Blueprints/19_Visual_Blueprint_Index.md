## Visual Design Direction

Final implementation should preserve:
- premium, non-generic FDG visual identity;
- near-full-bleed hospitality/property hero where useful;
- transparent live-data overlays;
- Attention Center exception intelligence;
- mobile-first field/staff flows;
- property/room spatial context where operationally useful;
- status animation only when it communicates state;
- evidence/freshness on material cards;
- real interaction in demos.

Do not imitate competitor screenshots.
