## Important Existing-Repository Conflict

folder families (for example two different `01_...`, `02_...`, etc.).
Therefore this package must be **merged under audit**, not copied
blindly. The target destinations above use existing folder names found
in the local tree, but document IDs and exact placement should be
checked against authoritative FBIS indexes before promotion.
