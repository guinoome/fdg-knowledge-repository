# FPJIS-0000 --- Project Intelligence System Integration Note

**Status:** Proposed integration note

## Why FPJIS Exists

FDG needs a governed place where project ideas, discoveries,
opportunities, validation evidence, architecture, plans, execution
knowledge, outcomes, and commercialization learning persist beyond
individual conversations.

## Proposed Canonical Lifecycle

`Idea → Discovery → Validation → Architecture → Planning → Execution → Operations → Review/Learning → Commercialization/Archive`

## Relationship to Existing `Projects/`

Do not blindly replace the existing root `Projects/` workspace. It
currently serves implementation/working artifacts. FPJIS should preserve
governed project intelligence and portfolio lifecycle. A future
repository audit should formalize the boundary and linking standard
between FPJIS records and active `Projects/Active/...` implementations.

## Rule

Every material FDG project idea should enter FPJIS early enough that it
can be found, evaluated, linked, and revisited---even if it is not yet
approved for execution.
