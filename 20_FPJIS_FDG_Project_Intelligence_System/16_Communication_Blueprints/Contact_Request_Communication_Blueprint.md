# Contact / Request / Communication Blueprint

Standardized across FDG projects.

USER
↓
CONTACT ADMIN
↓
REQUEST
↓
COMMUNICATION RECORD
↓
ADMIN REVIEW
↓
DECISION
↓
ACTION / WORKFLOW

Possible actions:
- email
- notification
- task
- approval
- escalation
- CRM record
- follow-up
- automation

The communication record should preserve:
- requester
- request
- timestamp
- status
- assigned owner
- decision
- action
- revision/history
