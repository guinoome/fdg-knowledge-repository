# Implementation Package Operating Rules

1. Read 00_PROJECT first.
2. Read only the blueprints relevant to the assigned work package.
3. Review dependencies before starting.
4. Use references only for their recorded purpose.
5. Do not invent missing requirements.
6. Do not silently expand scope.
7. Work in parallel only where dependency analysis permits.
8. Validate locally first.
9. Record implementation evidence.
10. Return discovered blueprint gaps for FPJIS review.
