# Security Blueprint

Define:
- authentication
- authorization
- roles
- permissions
- data classification
- secrets
- credential handling
- session management
- audit logging
- abuse controls
- file upload controls
- API security
- payment security
- backup/security boundaries
- project isolation
- incident considerations

Security requirements must be proportionate to actual risk and supported by evidence.
