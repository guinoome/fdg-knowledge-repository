# Intelligence Consultation Blueprint

FPJIS can request domain intelligence from other FDG Intelligence Systems.

Examples:
- FEIS: engineering requirements
- FBIS: business analysis
- FSIS: security
- FLIS: legal/regulatory
- FBPOIS: building/plant operations
- FWAIS: workflow automation

Flow:

FPJIS
↓
DOMAIN INTELLIGENCE REQUEST
↓
SPECIALIZED INTELLIGENCE SYSTEM
↓
EVIDENCE / RECOMMENDATION / CONSTRAINTS
↓
FPJIS BLUEPRINT
↓
DECISION / REVISION

The consulted intelligence system remains responsible for its domain.
FPJIS remains responsible for the project blueprint.
