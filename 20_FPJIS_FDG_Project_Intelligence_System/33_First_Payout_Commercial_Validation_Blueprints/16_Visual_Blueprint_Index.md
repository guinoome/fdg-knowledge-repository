## UI Visual Direction

Any final implementation should preserve:
- premium non-generic FDG character;
- near-full-bleed hero with transparent live-data overlay;
- decision-oriented Attention Center;
- responsive desktop/tablet/mobile layouts;
- live/real interaction rather than screenshot-only demonstrations;
- evidence/provenance visible on material decisions.

These diagrams are architecture blueprints, not final visual design approval.
