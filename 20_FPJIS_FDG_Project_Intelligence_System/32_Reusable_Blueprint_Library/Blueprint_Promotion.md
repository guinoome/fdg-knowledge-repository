# Blueprint Promotion

A project should identify reusable assets during closure.

Candidate blueprint:
- demonstrated in real project
- reviewed
- validated
- documented
- generalized
- stripped of project-specific assumptions
- versioned

Then promote to:

99_Blueprint_Library/

Future projects can:
- reuse
- extend
- specialize
- replace

Success metric:
Each completed FDG project should make subsequent projects faster and less ambiguous.
