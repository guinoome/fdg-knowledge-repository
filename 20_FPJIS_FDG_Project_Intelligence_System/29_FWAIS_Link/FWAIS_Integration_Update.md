# FWAIS ↔ FPJIS Integration Update

## Purpose

This note records the architectural relationship between FPJIS and FWAIS.

FPJIS identifies and blueprints automation opportunities during project planning.

FWAIS remains the specialist intelligence system for workflow automation.

## Flow

FPJIS
→ identify repetitive/rules-based/repeatable/reviewable/ROI-positive workflow
→ create Automation Blueprint
→ request FWAIS consultation
→ FWAIS analyzes automation opportunity
→ return workflow/automation recommendations
→ FPJIS incorporates approved results into project blueprints
→ implementation package may include automation work packages

## Important boundary

FPJIS does not replace FWAIS.

FWAIS provides workflow automation intelligence.
FPJIS governs the project blueprint and implementation readiness.

## Update to FWAIS knowledge

FWAIS should recognize FPJIS as a project-entry source for future automation candidates and as a consumer of FWAIS workflow-analysis capabilities.

When an FPJIS project contains:
- repetitive work
- rules-based decisions
- repeatable workflows
- reviewable outputs
- measurable ROI

FPJIS should consider requesting FWAIS analysis before implementation.

CONTACT ADMIN
→ REQUEST
→ COMMUNICATION RECORD
→ ADMIN REVIEW
→ DECISION
→ WORKFLOW
→ AUTOMATION

This standardized Communication/Request Blueprint can later become an FWAIS automation candidate.
