# Future Melanie Project — Master Index

## Purpose

**Melanie** is a future FDG implementation project that will turn existing governed FDG engineering-company, construction-management, knowledge-library, workflow, commercial, platform-experience, security, audit, legal/compliance, and intelligence standards into one coherent commercial product family.

Melanie does **not** create a new source of truth.

The canonical source of truth remains the existing FDG Knowledge Repository.

Melanie consumes, implements, validates, and returns learning to that repository.

## Non-Depletion Rule

Melanie is an implementation project over existing FDG architecture.

It shall not:
- replace FEIS-CM with a second construction system;
- duplicate DCKL knowledge;
- rewrite existing approved standards without controlled evolution;
- merge FPJIS into construction operations;
- turn FBIS, FLIS, FSIS, FAIS, or FWAIS into construction submodules;
- make conversation history the source of truth;
- claim features are built merely because blueprints exist.
