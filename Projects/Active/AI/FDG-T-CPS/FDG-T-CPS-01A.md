# PRIMARY OBJECTIVE

Develop a professional desktop-class engineering application that performs complete analysis and design of:

* Transfer Pump Systems
* Constant Pressure Systems
* Booster Pump Systems
* Domestic Water Distribution Systems

The application shall perform the entire engineering workflow from project creation to final report generation.

The software must operate completely offline.

No backend server.

No database server.

No installation.

No cloud dependency.

Everything shall execute inside a single HTML application.

---

# FINAL OUTPUT

The final generated application shall be saved as:

FDG-T-CPS.html

This file shall contain:

* HTML
* CSS
* JavaScript

embedded in one document.

No external project files shall be required except optional third-party JavaScript libraries loaded through CDN with an offline fallback if implemented.
