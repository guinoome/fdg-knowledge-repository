# Premium theme and fidelity decisions

User reference: FDG Solar Visayas investment-summary image supplied in chat; viewed as visual reference only. No client's identity, contact details, prices, savings claims or marketing promises were copied.

| Reference cue | Implementation | Verification / decision |
|---|---|---|
| Deep navy to warm red backdrop | Layered navy/red shell with dark glass-like panels | Desktop and phone screenshots inspected |
| Gold headings and rules | Gold eyebrow labels, brand rule and section hierarchy | Matches supplied art direction |
| Bold white brand / figures | Strong FDG Construction brand, white values, restrained letter spacing | Sidebar clipping corrected at 1080 px |
| Solid gold primary card / actions | Gold emphasis metric and primary save actions | Black/dark text maintains readability |
| Green / blue card edges | Semantic progress and secondary data accents | Same family as supplied metric cards |
| Spacious editorial summary | Project header and decision-ready metric rows | Adapted for dense operational forms |
| Print export | Light paper, hidden navigation/actions | Intentional: readable economical PDF, not the dark quotation poster |
| Phone access | Horizontal area and utility rails, responsive cards/forms | Actual390 px viewport; no document overflow in tested views |

The reference is a quotation poster; this product is a construction workflow. Forms, tables, evidence controls, lifecycle navigation and status explanations are deliberate functional adaptations. Native system typography and CSS preserve offline independence. No external font, image service, CDN or network request is required.

Visual evidence contains synthetic example data only. Screenshots and PDFs were generated in RAM and uploaded directly to GitHub; no local project artifacts were saved.
