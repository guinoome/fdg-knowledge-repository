| Reference quality | Implemented treatment | Evidence / intentional deviation |
| --- | --- | --- |
| Dark evergreen FDG identity | Persistent evergreen desktop rail, compact mobile mark, protected lime action color | Matches the reference hierarchy without copying a third-party brand |
| Editorial Filipino business environment | Original generated FDG ecosystem asset spanning fuel, food, bakery, and auto service | No third-party trade dress; image is labelled an FDG-owned concept environment |
| Clear client-magnet proposition | “One account. Every business you’re building.” with immediate Discover and My Platforms actions | Fake network statistics and testimonial claims were intentionally removed |
| Rich platform catalog | Outcome-led category rail and nine domain-native module entries | Only Fuel is labelled connected; all unfinished verticals are explicitly roadmap or prototype preview |
| Unified account / separate modules | `My Platforms` shows independent instances, plan, branch, lifecycle, and workspace action | Production login and entitlements are not claimed |
| Activation storytelling | Plan → Branch → Review → Payment boundary with visible module ownership and price calculation | Final action creates only a local trial; no payment fields or provider logo are shown |
| Mobile-first composition | Dedicated mobile header, bottom dock, horizontal filter rails, stacked cards, thumb-reachable primary actions | This is a purpose-built mobile layout, not a scaled desktop dashboard |
| Portfolio intelligence | Shared subscription and branch context plus workbook-grounded Fuel proof | Cross-domain “health scores” were intentionally rejected until domain evidence exists |
| Operational trust | Explicit local-prototype banners, payment boundary, permission boundary, and source-exception count | Marketing hierarchy does not obscure evidence or invent live capability |
| Connected Fuel workflow | My Platforms opens the fuel workspace; closeout inherits the prior accepted final readings, offers optional local OCR for the new final reading, and product analysis spans daily through annual evidence | The internal intelligence ownership map is intentionally kept out of the client runtime; hourly remains a labelled source gap until timestamped transactions exist |

- No console errors remained in the validated workflow.
- The connected Fuel Operations workspace remains available under `/fuel-station/`.
