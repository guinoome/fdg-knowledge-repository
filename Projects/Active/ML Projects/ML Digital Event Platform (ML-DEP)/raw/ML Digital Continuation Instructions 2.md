# ML Digital Invitation Platform

## Engineering Instructions for Template Development

**Version:** 1.0
**Purpose:** Continue development of the ML Digital Invitation platform with a premium, world-class template system focused on real visual impact, Filipino event use cases, and responsive preview behavior.

---

## 1. Objective

Build invitation templates that feel like premium commercial products, not basic layouts.

The template system must support realistic, high-quality visual presentation using actual event-style imagery such as:

* Birthday photos
* Wedding photos
* Debut photos
* Christening photos
* Anniversary photos
* Graduation photos
* Filipino family event photos
* Cultural and community celebration photos

The result must feel visually authentic, emotionally engaging, and suitable for real clients.

---

## 2. Core Design Direction

Every template must be designed to reach world-class quality.

Design expectations:

* Premium visual composition
* Strong typography
* High-end spacing and alignment
* Elegant image treatment
* Professional color harmony
* Modern marketing-grade presentation
* Smooth responsiveness
* Clean mobile and desktop behavior
* Visually attractive for Filipino users
* Suitable for both formal and celebratory events

Avoid flat, generic, or toy-like template designs.

Do not rely only on basic shapes, plain backgrounds, or text-only layouts.

---

## 3. Image-Driven Template Strategy

Templates should use actual-looking event imagery as the main visual anchor.

Preferred image styles:

* Realistic birthday portrait photography
* Elegant wedding couple photography
* Stylish debut event portrait photography
* Warm family celebration imagery
* Formal event photography
* Soft cinematic lighting
* High-resolution hero images
* Emotionally expressive visuals

Use images as the primary design asset, not as decoration only.

Each template should feel like a finished marketing product with strong visual storytelling.

---

## 4. Filipino Event Options

The template library must include Filipino event types and styling preferences.

Required Filipino-focused options:

* Birthday
* Wedding
* Debut
* Christening
* Anniversary
* Graduation
* Baptism
* Reunion
* Family Celebration
* Corporate Event
* Community Event
* Fiesta-style celebration
* Religious celebration
* Custom Filipino event

Templates should feel natural for Filipino users in tone, style, and event structure.

---

## 5. Template Quality Standard

Every template must be world class.

That means each one must have:

* Clear visual hierarchy
* Strong hero section
* Beautiful photo framing
* Balanced use of white space
* High contrast and readability
* Consistent spacing
* Responsive layout logic
* Professional CTA placement
* Polished footer
* Refined overall composition

Each template should look like something a premium event agency would sell.

---

## 6. Preview Behavior Requirement

The preview system must automatically resize based on the viewing context.

Required behavior:

* Desktop preview should render in a wide, polished format
* Mobile preview should automatically adapt to a narrow vertical layout
* Tablet preview should scale appropriately between both
* Content should remain readable and visually balanced in all views
* No manual zooming should be required for normal preview use

Preview must feel fluid and intelligent.

Do not let desktop layouts break on mobile.

Do not let mobile layouts look compressed on desktop.

---

## 7. QR Code Placement

Every invitation preview must include a QR code at the bottom.

QR code requirements:

* Positioned consistently at the bottom section
* Visually separated from the main content
* Cleanly aligned
* Easily scannable
* Not obstructing the design
* Works in both web and mobile preview modes

The QR code should feel like a functional part of the invitation, not an afterthought.

---

## 8. Layout Behavior Rules

The system must support adaptive rendering.

When previewing:

* Web view should prioritize full visual composition
* Mobile view should prioritize vertical stacking and readability
* Images should crop intelligently
* Text should not overflow
* Buttons and interactive elements should remain usable
* QR code should stay visible near the bottom
* No layout should require manual correction per device

---

## 9. Functional Requirements

Every template must be fully functional.

This means:

* Template renders correctly
* Images load properly
* Sections display in correct order
* Preview mode works reliably
* Mobile and desktop behave correctly
* QR code is visible and positioned correctly
* Event information is readable
* No broken layout states

A template is not complete unless it works visually and functionally.

---

## 10. Template System Expectations

The template engine should support:

* Template selection
* Image swapping
* Event type switching
* Content editing
* Responsive preview
* QR code generation/display
* Section reordering when needed
* Filipino event variations

The architecture should make future template expansion easy.

---

## 11. Engineering Priority Order

Follow this order:

1. Build world-class templates
2. Use actual image-based presentation
3. Support Filipino event categories
4. Implement automatic responsive preview
5. Position QR code at the bottom
6. Validate visual quality on web and mobile
7. Refine polish and consistency
8. Remove layout defects

---

## 12. Quality Control Checklist

Before accepting any template, verify the following:

* Looks premium on desktop
* Looks premium on mobile
* Uses strong imagery
* Supports Filipino event use cases
* QR code appears at the bottom
* Text remains readable
* Spacing is balanced
* No visual clipping
* No broken sections
* No amateur styling
* No low-quality fallback composition

---

## 13. Implementation Standard

Treat every template as a client-facing premium product.

Do not ship anything that looks like a placeholder.

Do not ship anything that looks generic.

Do not ship anything that fails on mobile.

Do not ship anything where the QR code placement feels random.

---

## 14. Final Development Instruction

Continue development with image-first, premium-quality, Filipino-market-ready invitation templates.

The platform must feel like a world-class invitation studio with automatic responsive preview behavior and a consistent QR code footer for every design.

This is the standard to follow for all future template work.
