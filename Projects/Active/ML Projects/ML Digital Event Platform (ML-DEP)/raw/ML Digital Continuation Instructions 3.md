# ML Digital Invitation Platform
## Claude Code Engineering Task
### Context → Harness → Loop Engineering
Version: 1.0

---

# Mission

Modernize the entire ML Digital Invitation template library.

The attached reference designs are **design inspirations only**.

Do NOT reproduce or copy them.

Instead:

- Study their visual language
- Understand their composition
- Understand their animation style
- Understand their emotional appeal
- Create original ML Digital Invitation templates inspired by those qualities.

Every finished template must be unique and recognizable as an ML Digital Invitation design.

---

# Context

Current templates no longer meet the desired quality level.

The platform should compete with premium invitation providers.

The new template system should feel modern, cinematic, premium, elegant, and emotionally engaging.

The objective is to build a template library that users are excited to share.

---

# Design Rules

The attached samples are references only.

Never duplicate:

- Layout
- Graphics
- Illustrations
- Images
- Typography
- Decorative assets
- Animations

Instead, capture only the overall vibe and design quality.

Each ML template must become an original work.

---

# Template Philosophy

Every template should tell a story.

Avoid generic invitation cards.

Design immersive invitation experiences.

The invitation should feel like a premium event website rather than a static poster.

---

# Required Event Categories

Create distinct design systems for:

- Wedding
- Birthday
- Kids Birthday
- Debut
- Christening
- Baptism
- Graduation
- Anniversary
- Baby Shower
- Engagement
- Corporate Event
- Reunion
- Fiesta
- Holiday Party
- Memorial
- Custom Event

Each category must have its own visual identity.

Avoid sharing the same layout across categories.

---

# Visual Direction

Aim for:

- Luxury
- Elegant
- Cinematic
- Editorial
- Premium
- Minimal where appropriate
- Modern
- Emotional
- Highly polished

Each template should immediately communicate its event type.

---

# Image Strategy

Templates should support:

- Large hero photos
- Portrait photography
- Landscape photography
- Multiple gallery images
- Background imagery
- Decorative overlays
- Dynamic cropping

Images should drive the overall visual experience.

---

# Animation System

Introduce tasteful animation throughout the templates.

Possible examples include:

- Hero reveal
- Fade transitions
- Scroll animations
- Floating decorative elements
- Parallax effects
- Smooth section transitions
- Countdown animations
- Gallery animations
- Timeline animations
- RSVP success animations

Animations must feel premium.

Avoid excessive or distracting motion.

---

# Video Support

Add optional video capabilities.

Examples:

- Hero background video
- Event highlight video
- Couple story video
- Birthday slideshow
- Family montage
- Embedded promotional video

Requirements:

- Optional per template
- Responsive
- Optimized loading
- Graceful fallback when no video exists

---

# Music Support

Introduce optional background music.

Requirements:

- User-controlled playback
- Mute / unmute
- Mobile-friendly behavior
- No forced autoplay where browsers prohibit it
- Graceful fallback if audio is unavailable

Music should enhance the experience without reducing usability.

---

# Template Uniqueness

Every template must have its own:

- Layout
- Typography
- Animation behavior
- Color system
- Decorative elements
- Section ordering
- Hero presentation
- Visual personality

Avoid cloning one template into multiple color variations.

Users should immediately recognize that each template is different.

---

# Responsive Preview

The preview engine must automatically adapt to:

- Desktop
- Tablet
- Mobile

The preview should accurately reflect the final user experience without requiring manual resizing.

---

# QR Code

Every template should reserve a consistent area for a QR code near the bottom.

Requirements:

- Clearly visible
- Easy to scan
- Integrated naturally into the design
- Responsive on all devices

---

# Engineering Requirements

Maintain:

- Modular architecture
- Reusable components
- Clean code
- Separation of concerns
- Performance optimization
- Accessibility
- Maintainability

Avoid duplicate implementation.

---

# Harness Engineering

Work in small, reviewable increments.

Suggested workflow:

1. Analyze attached references.
2. Extract reusable design principles.
3. Define unique visual directions for each event category.
4. Build reusable template components.
5. Apply category-specific styling.
6. Add animation support.
7. Add video support.
8. Add music support.
9. Validate responsiveness.
10. Refine for performance and maintainability.

Do not attempt to complete everything in a single large change.

---

# Loop Engineering

For every completed template, perform an internal review cycle:

1. Implement.
2. Compare against the design goals.
3. Improve layout and hierarchy.
4. Improve responsiveness.
5. Improve animations.
6. Verify accessibility.
7. Optimize assets.
8. Remove duplicate code.
9. Validate functionality.
10. Repeat until the template meets the acceptance criteria.

Do not stop after the first working implementation.

---

# Acceptance Criteria

A template is complete only if it:

- Is visually original
- Is inspired by, but does not copy, the reference designs
- Has a unique identity
- Supports responsive layouts
- Supports optional animation
- Supports optional video
- Supports optional music
- Maintains excellent performance
- Meets premium commercial design quality
- Works reliably across supported devices

---

# Final Instruction

Think like a senior product designer and front-end engineer.

The goal is not simply to recreate invitation templates.

The goal is to build a world-class digital invitation experience that reflects the ML Digital Invitation brand while remaining original, technically maintainable, and ready for future expansion.
