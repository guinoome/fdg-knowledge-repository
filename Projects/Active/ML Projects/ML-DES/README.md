# ML-DES (code repo)

This repository contains scaffolding for the ML Digital Event Suite (ML-DES).

Structure:

- `backend/` - minimal Flask API demo
- `frontend/` - static frontend prototype
- `docs/` - architecture and roadmap
- `infra/` - deployment notes
- `scripts/` - setup scripts
- `tests/` - simple tests

See top-level docs for full spec and requirements.
