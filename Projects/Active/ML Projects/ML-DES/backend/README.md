# Backend (Python/Flask)

This folder contains a minimal Flask app to demonstrate the API surface.

Run locally:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

API:
- `GET /api/ping` -> health check
