# Service Delivery Framework

Service delivery converts the approved definition into an executed engagement.

Minimum phases:
`Intake -> Qualification -> Confirm Requirements -> Plan -> Execute -> Verify -> Deliver -> Accept -> Close -> Learn`

Each phase should have entry conditions, responsibilities, required records, decision gates, and exit conditions proportional to service risk.

Project-specific planning belongs in FPJIS; FSvIS provides the reusable service delivery pattern.
