# Continuous Service Improvement Framework

Improvement sources include performance trends, nonconformances, complaints, project postmortems, regulatory changes, technical advances, cost shifts, collaborator feedback, and service experiments.

Improvement flow:
`Capture -> Triage -> Analyze -> Prioritize -> Test -> Approve -> Implement -> Verify Effectiveness -> Standardize`

Protect active milestones: improvements that are valuable but not required for current acceptance should enter the roadmap rather than destabilize ongoing delivery.
