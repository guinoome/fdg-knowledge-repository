# Service Classification and Status Register

## Suggested Classification
- Engineering
- Consulting
- Assessment/Audit
- Design
- Operations and Maintenance
- Digital/Platform
- Internal Organizational Service
- Experimental/Future

## Status
Candidate, Draft, Review, Approved, Active, Deprecated, Retired.

## Minimum Register Fields
`Service ID | Name | Category | Owner | Version | Maturity | Status | Primary Outcome | Dependencies | Last Review | Next Action`

The register should eventually be machine-readable, while Markdown remains the human governance layer.
