# 05 Multidiscipline Engineering Intelligence — Master Index

**System:** FDG Engineering Intelligence Systems (FEIS)  
**Branch:** Multidiscipline Engineering Intelligence (MDE)  
**Status:** Approved Direction — Cross-Discipline Integration Layer  
**Owner / Final Authority:** Francis  
**Effective:** 2026-10-05

## Purpose

Provide one canonical FEIS integration layer for Architectural, Civil, Mechanical, Electrical, Plumbing/Sanitary, Fire Protection, and Auxiliary/ELV engineering capability without creating a separate operating system or duplicated project-management module for every profession.

## Governing Principle

> Do not build a new module simply because a course, vendor, profession, or job title identifies a role.

Instead:

1. extract the underlying capability
2. place universal project functions in the shared Project Operations / Project Intelligence layer
3. place discipline-specific technical semantics in the appropriate FEIS discipline capability
4. expose the combined capability through a role-specific Workbench
5. preserve one shared project truth
