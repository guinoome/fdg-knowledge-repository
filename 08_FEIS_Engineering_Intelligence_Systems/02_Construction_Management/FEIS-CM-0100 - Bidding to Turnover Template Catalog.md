# FEIS-CM-0100 — Bidding to Turnover Template Catalog

**Status:** Approved Direction — Canonical Initial Catalog  
**Effective:** 2026-09-30  
**Market:** Philippines first

## Purpose

Define the initial construction-management template and workflow catalog from bidding through turnover.

These are not intended to remain isolated documents. Each template should progressively become a governed schema, workflow, view, report or export backed by structured project data.

## Template Design Rule

Each future template/capability should define, where applicable:

- Template / capability ID
- lifecycle stage
- purpose
- responsible role
- required inputs
- structured fields
- evidence requirements
- workflow / status
- reviewer / approval authority
- dependencies
- derived outputs
- revision/version
- jurisdiction
- source/provenance
- related knowledge
- commercial package

## Automation Priority

The first high-leverage implementation should connect:

Site Progress Event → Daily Report → Weekly Report → Project Progress → BOQ Accomplishment → QA/QC State → Billing Draft → Management Dashboard

This chain reduces repeated encoding while preserving validation boundaries.
