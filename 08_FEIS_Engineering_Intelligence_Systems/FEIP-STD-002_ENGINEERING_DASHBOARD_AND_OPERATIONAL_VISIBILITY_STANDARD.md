# Purpose

This standard defines the structure, requirements, and operating principles of the FEIP Engineering Dashboard.

---

# Core Principle

A dashboard is not a display screen.

It is an engineering command interface.

---

# Objective

The FEIP Engineering Dashboard shall provide:

- current operational condition
- critical issues
- performance status
- resource visibility
- decision support

within minutes.
