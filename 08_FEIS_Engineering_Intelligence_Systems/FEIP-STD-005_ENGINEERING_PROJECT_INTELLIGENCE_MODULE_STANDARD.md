# Purpose

This standard defines the structure and operating principles of the FEIP Engineering Project Intelligence Module.

---

# Core Principle

A project is not only a construction activity.

It is an engineering knowledge creation process.

---

# Objective

The FEIP Project Intelligence Module shall support:

- project planning
- engineering evaluation
- scope management
- cost control
- execution monitoring
- project documentation
- lessons learned
