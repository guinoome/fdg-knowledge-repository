# FEIS-DCKL-0000 — FDG Digital Construction & Engineering Knowledge Library Architecture

**System Parent:** FDG Engineering Intelligence Systems (FEIS)  
**Status:** Approved Direction — Canonical Knowledge / Commercialization Layer  
**Owner / Final Authority:** Francis  
**Initial Market:** Philippines  
**Future Direction:** International jurisdiction packs

## Purpose

Create a deliberately cataloged, governed and commercially reusable construction and engineering knowledge layer inside the existing FDG Knowledge Repository.

This is not a separate repository.

The FDG Knowledge Repository remains the source of truth.

## Core Principle

> Create once → govern once → structure once → reuse everywhere → distribute through many channels → capture operational learning → improve the canonical knowledge.

## Primary Unit of Value

The canonical unit should evolve beyond a downloadable file.

Preferred model:

Knowledge Object + Workflow + Rules + Evidence + Computation + Authority + Output + Provenance

Examples:

- checklist → executable inspection capability
- spreadsheet → governed calculation capability
- daily report template → event-driven reporting projection
- commissioning form → readiness/test/evidence workflow
- billing form → controlled commercial projection
- handover checklist → closeout state machine

Files such as XLSX, DOCX and PDF may remain supported outputs where useful.

## Knowledge Taxonomy

Every construction/engineering knowledge asset should be classifiable by relevant dimensions such as:

- lifecycle stage
- discipline
- company function
- project role
- project / asset type
- work package
- system / equipment
- jurisdiction
- record type
- required inputs
- outputs
- approval authority
- evidence requirements
- applicable standard/code/reference
- commercial package
- version / status
- provenance / source
- dependencies
- lessons learned

## Initial Philippine Scope

Prioritize Philippine construction and engineering operating reality, including:

- local project practices
- Philippine regulatory references where applicable
- locally used terminology and forms
- peso-based cost/commercial workflows
- contractor/subcontractor operating patterns
- MEPF and building-services practice
- client/consultant/contractor coordination
- local approval and documentation expectations

Universal engineering workflow must remain separable from Philippine jurisdiction-specific content.

## Commercialization Ladder

Knowledge may be distributed through governed levels such as:

1. public educational content / glossary
2. free lead-magnet resources
3. paid original templates or reference packs
4. commercial FDG Engineering modules
5. bundled company systems
6. enterprise / white-label deployments
7. professional services / consulting
8. future APIs or partner capability distribution

## Research and Source Integrity

External sites and marketplaces may be used to identify:

- common workflow pain points
- market taxonomy
- popular resource categories
- commercial packaging patterns
- terminology
- user demand signals

FDG must not copy, resell or reconstruct proprietary/copyrighted paid templates without rights.

FDG knowledge should be original, client-authorized, public-domain/official, appropriately licensed, or otherwise legally usable, with provenance retained.

## Knowledge Flywheel

Operational Work → Structured Evidence → Review → Lesson Learned → Governed Knowledge → FDG Module / Template / Training / Service → New Operational Work

## Role-Aware Executable Knowledge Extension — 2026-10-04

The DCKL may package approved knowledge not only as documents/templates, but as provider-neutral executable guidance for project roles.

A reusable role capability may combine:

Knowledge Object + Task Definition + Required Context + Rules + Evidence + Verification + Workflow Destination + Authority + Acceptance Tests

For Construction Management, the first role-aware implementation is the [[08_FEIS_Engineering_Intelligence_Systems/02_Construction_Management/FEIS-CM-0005 - Construction Manager Role Intelligence and Guided Workflow Standard|FDG Construction Manager Workbench]].

The DCKL should eventually support governed role packs such as:

- Construction Manager
- Site Engineer
- QA/QC
- Project Controls
- Commercial / QS
- Testing & Commissioning
- Turnover / Closeout

These are not separate knowledge silos. They are different governed experiences over shared canonical knowledge and project data.

Embedded learning and competency evidence are governed by [[08_FEIS_Engineering_Intelligence_Systems/02_Construction_Management/FEIS-CM-0007 - Construction Manager Embedded Learning and Competency Standard|FEIS-CM-0007]].

External benchmark provenance for the 2026-10-04 construction-manager upgrade is preserved in [[08_FEIS_Engineering_Intelligence_Systems/02_Construction_Management/FEIS-CM-RSCH-0001 - Tixu Construction Manager Benchmark Extraction 2026-10-04|FEIS-CM-RSCH-0001]].
