# Purpose

This standard defines the architecture and operating relationship between FEIP and Nex Core Intelligence.

---

# Core Principle

FEIP provides engineering context.

Nex provides engineering reasoning.

Together they create FDG Engineering Intelligence.

---

# Objective

The Nex Core Integration shall provide:

- evidence-based recommendations
- engineering reasoning support
- knowledge retrieval
- calculation assistance
- decision support
- continuous learning
