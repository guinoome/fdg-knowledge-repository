# Purpose

This standard defines the security, access control, governance, and accountability framework of FEIP.

---

# Core Principle

Engineering information must be accessible to the right people while protected from unauthorized modification.

---

# Objective

The FEIP Security and Governance Module shall provide:

- user access control
- data ownership
- approval authority
- auditability
- cybersecurity protection
- governance discipline

# Approved Evolution Addendum — 2026-09-30

## Named User Subscription Control

Commercial FDG Engineering modules should use named-user seats for accountable human activity.

The default standard paid-user rule is one active interactive session per named user, with controlled session takeover and revocation of the prior session.

Geographic location or IP change should be a security/risk signal rather than the sole licensing control.

Offline-capable field modules should use a governed offline session/device lease or equivalent control that preserves identity, auditability, bounded validity and revocation.

See [[08_FEIS_Engineering_Intelligence_Systems/02_Construction_Management/FEIS-CM-0004 - Named User Session and Subscription Control Standard|Named User Session and Subscription Control Standard]].
