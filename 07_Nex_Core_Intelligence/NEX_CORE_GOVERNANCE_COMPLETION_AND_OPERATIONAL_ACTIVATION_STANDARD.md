# Activation Gate Criteria

Nex Core may enter operation when:

---

# 1. Governance Readiness

Requirements:

✓ Standards approved

✓ Ownership defined

✓ Responsibilities assigned

✓ Change process established

---

# 2. Knowledge Readiness

Requirements:

✓ Repository structure exists

✓ Naming conventions established

✓ Knowledge capture process active

✓ Important decisions recorded

---

# 3. Workflow Readiness

Requirements:

✓ Work package process defined

✓ Context transfer method available

✓ Review process established

✓ Output standards available

---

# 4. Technical Readiness

Requirements:

✓ Required systems available

✓ Access controls implemented

✓ Backup strategy defined

✓ Integration boundaries understood

---

# 5. Human Readiness

Requirements:

✓ Users understand operating model

✓ Collaborators understand responsibilities

✓ Review discipline accepted

# Activation Risks

---

## Overengineering

Building too much before proving value.

---

## Low Adoption

Creating systems without usage discipline.

---

## Missing Feedback

Failing to improve after experience.

---

## Governance Without Execution

Creating rules without operational behavior.

# Success Definition

Nex Core is successfully activated when:

- knowledge is captured consistently
- decisions are traceable
- engineering work improves
- collaborators operate with shared context
- capability grows over time
