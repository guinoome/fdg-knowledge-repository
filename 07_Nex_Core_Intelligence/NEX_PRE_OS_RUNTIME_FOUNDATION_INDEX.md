# Purpose

Give Codex, Claude Code, local-model collaborators, and future agents the minimum authoritative reading path needed to build NEX v0.1-alpha without repeatedly analyzing the entire FDG Knowledge Repository.

This is a runtime bridge, not a new Intelligence System.

# Immediate Goal

```text
User
  → Nex
  → FDG Knowledge Repository
  → canonical/context resolution
  → one controlled skill/action
  → validation
  → execution ledger / memory
  → Nex response
```

# First Heartbeat Proof Commands

1. `Nex, find the current FPJIS architecture.`
2. `Nex, create this project artifact in the correct permitted location.`
3. `Nex, record this approved decision.`

Do not declare operational until these pass repeatedly, denied writes are denied, and controlled writes are validated/recoverable.

# Operational Continuity Rule

```text
One governed source of truth
        ↓
One assignment owner
        ↓
One clean context/handoff package
        ↓
One required validation path
```

Existing repository standards already govern ownership, handoff, context, and approval. The new documents close runtime gaps only.

# Do Not Duplicate

Do not create competing standards for authority levels, generic context, collaborator handoff/ownership, knowledge lifecycle, metadata status, security/trust, or validation/approval.

# v0.1-alpha Required

- local text runtime;
- repository retrieval;
- canonical truth resolution;
- minimal context routing;
- scoped permissions;
- one safe write;
- approved-decision recording;
- pre-write recovery reference;
- validation;
- execution ledger;
- persistent learning without silent canonical promotion.

# Deferred
