# Purpose

This standard defines the daily operating procedures for maintaining and using the FDG Knowledge Repository.

---

# Core Principle

Capture once.

Structure correctly.

Reuse continuously.

---

# Knowledge Repository Operating Model

```
Create

↓

Classify

↓

Connect

↓

Validate

↓

Use

↓

Improve

```

---

# Daily Knowledge Workflow

## Step 1 — Capture

Record important:

- decisions
- observations
- problems
- solutions
- references
- improvements

Do not rely on memory alone.

---

# Step 2 — Classify

Assign the correct knowledge type:

```
Principle

Standard

Procedure

Decision

Knowledge

Record

```

---

# Step 3 — Structure

Every important note should contain:

```
Purpose

Context

Information

Analysis

Conclusion

References

Related Knowledge

```

---

# Step 4 — Connect

Link related information:

Examples:

```
Problem

↓

Root Cause

↓

Solution

↓

Standard

↓

Future Application

```

---

# Step 5 — Validate

Determine:

- accuracy
- source reliability
- approval status
- applicability

---

# Knowledge Maintenance

Knowledge should be reviewed when:

- information changes
- standards update

# Version Control

Important documents require:

```
Version

Date

Change Description

Author

Approval

```

---

# Archive Procedure

Information should be archived when:

- replaced
- obsolete
- no longer active

Archive shall preserve:

- historical value
- previous decisions
- evolution history

---

# Search and Retrieval Procedure

Before creating new solutions:

Search existing knowledge.

Review:

- previous decisions
- similar problems
- validated methods

---

# Context Preparation Procedure

Before major work:

Create:

```
Objective

Background

Relevant Knowledge

Constraints

Expected Output

Validation Criteria

```

---

# Collaboration Procedure

When handing work to another contributor:

Provide:

- objective
- current status
- completed work
- pending decisions
- required action

---

# Knowledge Quality Rules

Good knowledge must be:

## Understandable

Another engineer can use it.

---

## Traceable

Evidence is available.

---

## Connected

Related information exists.

---

## Maintainable

Can evolve.

---

# Anti-Pattern Prevention

## Knowledge Dumping

Saving information without structure.

---

## Private Knowledge

Important knowledge existing only with individuals.

---

## Duplicate Documents

Multiple conflicting versions.

---

## Forgotten Knowledge

Useful information never reused.

---
