# Daily Knowledge Capture Rule

Capture information when:

- a problem is solved
- a new method is discovered
- a decision affects future work
- a failure creates learning

# Daily Operating Boundaries

Nex shall not:

- replace engineering accountability
- approve without authority
- create unsupported conclusions
- bypass validation

---

# Anti-Pattern Prevention

## Conversation-Only Intelligence

Useful knowledge disappearing in chats.

---

## No Closure

Tasks completed without learning capture.

---

## Information Overload

Capturing everything without value.

---

## Reactive Operation

Only using Nex during problems.

# Governing Principle

The purpose of daily Nex operation is not to add more work.

It is to make every engineering activity improve the next one.
