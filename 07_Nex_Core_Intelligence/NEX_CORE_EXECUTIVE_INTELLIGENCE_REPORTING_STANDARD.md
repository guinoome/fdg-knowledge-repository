# Purpose

This standard defines how Nex Core Intelligence transforms engineering information into executive-level decision support.

---

# Core Principle

Executives require clarity, not information overload.

---

# Executive Intelligence Objective

Provide visibility into:

- operational condition
- engineering performance
- risks
- decisions
- improvement opportunities

---

# Reporting Model

```
Data

↓

Information

↓

Analysis

↓

Insight

↓

Decision

```

---

# Executive Report Structure

Every executive intelligence report should contain:

```
Executive Summary

Current Status

Key Changes

Critical Risks

Performance Indicators

Required Decisions

Recommended Actions

Future Outlook

```

---

# 1. Executive Summary

Purpose:

Provide immediate understanding.

Should answer:

- What is happening?
- Why does it matter?
- What requires attention?

---

# 2. Current Status

Summarize:

- operational condition
- project status
- system health
- capability level

---

# 3. Key Changes

Identify:

- improvements
- failures
- major events
- important decisions

---

# 4. Risk Intelligence

Present:

```
Risk

Impact

Probability

Current Control

Required Action

```

---

# 5. Performance Intelligence

Report:

## Engineering Performance

Examples:

- work completion
- reliability
- efficiency

---

## Knowledge Performance

Examples:

- lessons captured
- reuse improvement

---

## System Performance

Examples:

- automation reliability
- workflow effectiveness

---

# 6. Decision Support

Important decisions should include:

```
Decision Required

Background

Options

Recommendation

Risk

Expected Outcome

```

---

# 7. Strategic Recommendations

Recommendations should include:

- evidence
- reasoning
- expected value
- implementation considerations

---

# Report Validation

Before release verify:

- data accuracy
- assumptions
- calculation basis
- recommendation logic

---

# Anti-Pattern Prevention

## Data Dump Reporting

Showing information without interpretation.

---

## Hidden Problems

Reporting only positive conditions.

---

## Excessive Detail

Replacing decisions with technical documents.

---

## Unsupported Recommendations

Providing opinions without evidence.

---

The purpose of executive intelligence is not to show activity.
