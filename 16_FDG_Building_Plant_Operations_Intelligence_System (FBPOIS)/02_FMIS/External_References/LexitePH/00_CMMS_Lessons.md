## Required FDG extension

FMIS should not stop at:

Asset → Work Order.

Target a richer engineering history:

Asset
→ Component
→ Condition
→ Failure
→ Cause
→ Action
→ Material
→ Labor
→ Cost
→ Verification
→ Outcome

## Engineering intelligence readiness

The data model should preserve sufficient context for FDG CORE to evaluate repeated failures, maintenance effectiveness, lifecycle cost, and root-cause evidence.
