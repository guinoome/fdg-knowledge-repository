# FDG FMIS Complete Handover

Corrected FMIS architecture package.

FMIS and FWIS are separate peer intelligence systems under FBPOIS.

FWIS = Operations.

FMIS = Maintenance / Plant Status.

Engineering Manager and Chief Engineer can access both.

Chief Engineer has executive-level combined visibility.

Director of Engineering is optional and may consolidate multiple Chief Engineers where authorized.
