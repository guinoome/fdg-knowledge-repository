# Purpose

This standard resolves recurrent ownership questions by assigning one primary accountable enterprise function while preserving required cross-functional reconciliation.

# Reconciliation Rule

Shared inputs do not create shared accountability. One function remains the primary owner of the specialty outcome; other functions supply evidence, approvals, controls, expertise, or acceptance.

# Segregation Rule

Where fraud, error, conflict of interest, professional liability, or assurance risk is material, request, approval, custody/receipt, accounting/payment, and independent audit should be separated where practical.

# Escalation

Unresolved ownership conflicts escalate through the Delegation Standard, Decision Authority Standard, Enterprise Operating Model, and Founder governance.
