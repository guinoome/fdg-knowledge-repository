# FMCIS-001 — Formal Engagement Lifecycle

**Status:** Not yet designed

This work package is the next architecture activity.

The final lifecycle shall define:

- engagement definition
- lifecycle states
- entry criteria
- exit criteria
- state transitions
- authority by state
- exception states
- scope-change rules
- reopening and completion rules
- records produced by each state

Do not add implementation details until the state machine is agreed.
