# FEXIS-AGENT-0000 - Agent Discoverability Intelligence

## Purpose

Enable external intelligent agents to understand FDG capabilities, determine relevance, evaluate evidence, and interact through approved interfaces.

## Agent-readable capability model

Identity
→ Capabilities
→ Services
→ Evidence
→ Constraints
→ Availability
→ Interfaces
→ Actions

## Principle

Agent interoperability must be explicit, governed, secure, and verifiable. Discoverability alone does not authorize an agent to execute an action.
