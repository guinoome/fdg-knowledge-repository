# FEXIS-INT-0000 - Integration Architecture

FEXIS integrates primarily through governed knowledge and standardized interfaces.

Primary relationships:

- FDG Knowledge Repository → authoritative knowledge
- FDG CORE → shared intelligence capabilities
- FEIS → engineering knowledge
- FBIS → business knowledge
- FBPOIS → building and plant operations knowledge
- FSIS → security and trust controls
- FPIS → platform intelligence

Integration shall minimize duplicated knowledge and preserve system boundaries.
