# FEXIS-SEO-0000 - Search Intelligence

Search Intelligence covers conventional search discoverability, including:

- Search intent
- Keyword intelligence
- Technical search optimization
- Information architecture
- Content discoverability
- Local search
- Search performance measurement

SEO is treated as one capability within FEXIS, not as the complete system.
