# FBIS Security and Audit

Requirements:
- least privilege
- secret isolation
- server-side provider credentials
- webhook authentication
- idempotency
- audit logging
- transaction traceability
- administrative action logging
- environment separation
- backup/recovery

Avoid storing payment-card data unless specifically required and architected for the applicable compliance obligations. Prefer provider-hosted/tokenized mechanisms.
