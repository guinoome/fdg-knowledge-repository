# FBIS Audit Model

Audit material events:
- order creation
- price calculation
- voucher application
- payment creation
- provider event
- validation result
- fulfillment activation
- refund
- cancellation
- settlement
- reconciliation
- administrative changes

Audit records should identify event, timestamp, actor/system, entity, previous state, new state, and evidence.
