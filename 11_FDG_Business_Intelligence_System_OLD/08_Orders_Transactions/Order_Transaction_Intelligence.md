# Order and Transaction Intelligence

Order lifecycle:

DRAFT
→ CREATED
→ PAYMENT_PENDING
→ CONFIRMED
→ FULFILLED
→ COMPLETED

Terminal alternatives:
CANCELLED
REFUNDED
EXPIRED

Orders must preserve immutable commercial evidence for the state that occurred.
