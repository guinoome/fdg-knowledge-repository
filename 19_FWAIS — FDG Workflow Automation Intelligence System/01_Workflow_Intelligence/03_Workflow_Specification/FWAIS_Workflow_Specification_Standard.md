# FWAIS Workflow Specification Standard

Every automation candidate should be specified independently of its implementation technology.

## Minimum specification

- Workflow ID
- Business problem
- Business owner
- Industry
- Geography
- Current process
- Target outcome
- Trigger
- Inputs
- Processing stages
- Business rules
- Decision points
- Human gates
- Outputs
- Failure conditions
- Escalation rules
- Security requirements
- Audit requirements
- Required capabilities
- Candidate integration mechanisms
- KPIs
- ROI hypothesis
- Test scenarios
- Recovery strategy
- Replacement strategy

## Example

RFQ
→ Document Intake
→ Scope Classification
→ Quantity Extraction
→ Validation
→ Cost Retrieval
→ Estimate
→ Margin Check
→ Human Approval
→ Proposal
→ Submission
→ Follow-up

The workflow is FDG-owned. The execution technology is an implementation detail.
