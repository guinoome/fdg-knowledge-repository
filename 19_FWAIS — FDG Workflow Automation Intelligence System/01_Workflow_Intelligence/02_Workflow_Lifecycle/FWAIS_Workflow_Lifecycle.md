# FWAIS Workflow Lifecycle

## Lifecycle

Observe
→ Discover
→ Model
→ Standardize
→ Evaluate
→ Specify
→ Build
→ Validate
→ Approve
→ Execute
→ Monitor
→ Recover
→ Measure
→ Learn
→ Improve

## Gate 1 — Business validity

Confirm the problem is real and measurable.

## Gate 2 — Workflow validity

Confirm the current process, rules, actors, data, exceptions, and outputs.

## Gate 3 — Automation qualification

Apply 5R + Safety where required.

## Gate 4 — Capability selection

Select the required capability before selecting a technology.

## Gate 5 — Validation

Test normal, boundary, failure, security, and human-escalation paths.

## Gate 6 — Operational readiness

Confirm observability, ownership, rollback/recovery, documentation, and support.

## Gate 7 — Outcome review

Measure actual value against the original business case.

## Gate 8 — Learning

Promote validated lessons into reusable organizational knowledge.
