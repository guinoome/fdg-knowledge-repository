# FWAIS Workflow Blueprint Template

Use this as the minimum neutral blueprint for a workflow candidate.

## Template

- Workflow ID
- Workflow name
- Business problem
- Business owner
- Industry
- Geography
- Current process
- Target outcome
- Trigger
- Inputs
- Processing stages
- Business rules
- Decision points
- Human gates
- Outputs
- Failure conditions
- Escalation rules
- Security requirements
- Audit requirements
- Required capabilities
- Candidate integration mechanisms
- KPIs
- ROI hypothesis
- Test scenarios
- Recovery strategy
- Replacement strategy

## Design rule

Document the workflow first.
Choose the implementation technology later.
