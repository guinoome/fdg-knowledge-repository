# FPJIS–FWAIS Integration Note

## Purpose

This note records the relationship between FPJIS and FWAIS.

## Relationship

FPJIS identifies and blueprints automation opportunities during project planning.

FWAIS remains the specialist intelligence system for workflow automation.

## Flow

FPJIS
→ identify repetitive / rules-based / repeatable / reviewable / ROI-positive work
→ create automation blueprint
→ request FWAIS consultation
→ FWAIS analyzes workflow and automation opportunity
→ return workflow / automation recommendations
→ FPJIS incorporates approved results into project blueprint

## Important boundary

FPJIS does not replace FWAIS.

FPJIS governs project blueprinting and implementation readiness.
FWAIS governs workflow automation intelligence.
