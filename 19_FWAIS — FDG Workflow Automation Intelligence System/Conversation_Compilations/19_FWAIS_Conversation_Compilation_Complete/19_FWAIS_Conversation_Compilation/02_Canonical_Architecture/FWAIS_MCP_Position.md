# FWAIS MCP Position

## Architectural decision

MCP itself is **NOT** an FDG Intelligence System.

MCP is an integration mechanism.

## Implication

The durable FDG capability is not “MCP ownership.”
The durable capability is **Integration Intelligence**.

## Therefore

FWAIS should never become “an MCP platform” as its identity.

Instead, FWAIS should be able to use or replace MCP alongside other mechanisms when appropriate.

## Selection rule

Choose the mechanism that best satisfies:

- capability fit
- evidence
- security
- reliability
- maintainability
- cost
- performance
- replaceability
