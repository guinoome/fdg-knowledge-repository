# FEXIS–FWAIS Continuous Learning

## Purpose

FEXIS and FWAIS work together to support controlled continuous learning from approved external sources.

## Responsibility split

### FEXIS
Discovers and analyzes information outside FDG.

### FWAIS
Automates and governs the recurring review workflow.

### Knowledge Repository
Stores approved organizational knowledge after validation.

## Supported source types

Approved sources may include:

- YouTube channels
- YouTube videos
- playlists
- websites
- documentation
- RSS feeds
- technical publications
- standards updates
- government sources
- vendor technical resources
- research repositories
- GitHub repositories

## Governance rule

Continuous learning does **not** mean uncontrolled automatic acceptance.

Automation may perform:

- discovery
- retrieval
- extraction
- comparison
- classification
- proposal generation

Authoritative knowledge changes still require governance and validation.

## Continuous learning workflow

External Source Registry
→ Scheduled Monitoring
→ Change Detection
→ Content Acquisition
→ Content Extraction
→ Evidence Assessment
→ Knowledge Comparison
→ Knowledge Delta Detection
→ Learning Proposal
→ Human Validation
→ Knowledge Integration
