# FWAIS Visual Direction

## Agreed visual direction

The next-generation FWAIS presentation should aim for:

- premium enterprise software feel
- clean and high-trust presentation
- strong motion / interactivity cues
- believable product realism
- limited but refined assistant-character use
- strong hierarchy
- less decorative clutter
- less excessive glow / neon saturation
- more FPIS-aligned platform maturity

## Design modes

### 1. Automation Control Center
Best for high-level overview and client selling.

### 2. Workflow Builder
Best for showing actual workflow design and interactive engineering capability.

### 3. Executive ROI / Business Impact Dashboard
Best for decision-makers and business-value discussions.

## Refined assistant-character role

The assistant character should act as:

- guide
- concierge
- explainer
- workflow assistant
- contextual helper

The character should **not** dominate the UI or make the platform feel toy-like.

## Recommended future enhancement

Ask FPIS to define:

- platform design language
- component hierarchy
- motion system
- tenant / client theming rules
- product realism standard
- assistant-character usage guardrails
