# 19_FWAIS — FDG Workflow Automation Intelligence System

## Purpose

FWAIS is the FDG Intelligence System responsible for discovering, modeling, standardizing, evaluating, automating, orchestrating, monitoring, and continuously improving organizational workflows.

FWAIS is an organizational capability, not a dependency on a specific automation platform.

## Core principle

> FDG workflows depend on capabilities, not vendors.

Automation engines, MCPs, APIs, SDKs, CLIs, providers, models, and platforms are replaceable implementation mechanisms.

## Core lifecycle

Observe → Discover → Model → Standardize → Evaluate → Specify → Build → Validate → Approve → Execute → Monitor → Recover → Measure → Learn → Improve

## Strategic geographic scope

1. Visayas, Philippines — initial demand intelligence and validation market
2. Philippines — national expansion
3. Global — validated reusable patterns and capabilities

## Architectural boundary

MCP is not an FDG Intelligence System. MCP is an integration mechanism.

FWAIS Integration Intelligence researches, evaluates, designs, creates, validates, registers, monitors, maintains, and replaces integrations.

FEXIS discovers and analyzes external information.

FDG CORE Intelligence provides higher-level capability, evidence, optimization, and decision intelligence.

FPJIS identifies project automation opportunities and consumes FWAIS analysis.

FMCIS may use FWAIS/FEXIS outputs when allocating work among collaborators.

## Governance

Automation candidates are qualified through the FDG 5R model:

- Repetitive
- Rules-based
- Repeatable
- Reviewable
- ROI-positive

For safety-critical or sensitive workflows:

**5R + Safety → Automation Candidate**

Technology is selected only after the business workflow and required capability are understood.
