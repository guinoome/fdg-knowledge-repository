# FEXIS + FWAIS Continuous External Learning

## Purpose

The FDG Ecosystem should continuously observe approved external information sources and identify changes that may improve, invalidate, or affect FDG capabilities.

FEXIS and FWAIS have complementary responsibilities.

## Separation of Responsibility

**FEXIS — FDG External Intelligence System**

Discovers and analyzes information outside FDG.

**FWAIS — FDG Workflow Automation Intelligence System**

Automates and governs the recurring process that acquires, reviews, validates, and routes that information.

**FDG Knowledge Repository**

Stores approved organizational knowledge.

## YouTube and External Source Monitoring

Approved sources may include:

- YouTube channels
- Specific YouTube videos
- Playlists
- Websites
- Documentation
- RSS feeds
- Technical publications
- Standards updates
- Government sources
- Vendor technical resources
- Research repositories
- GitHub repositories
- Other approved external sources

YouTube is one source type, not the architectural boundary.

## Continuous Learning Workflow

External Source Registry
→ Scheduled Monitoring
→ Change Detection
→ Content Acquisition
→ Content Extraction
→ Evidence Assessment
→ Knowledge Comparison
→ Knowledge Delta Detection
→ Learning Proposal
→ Human Validation
→ Knowledge Integration

## Important Governance Rule

Continuous learning does not mean uncontrolled automatic acceptance.

Automation may perform:

- Discovery
- Retrieval
- Extraction
- Comparison
- Classification
- Proposal generation

Authoritative knowledge changes must follow FDG knowledge governance and appropriate human validation.

## Example

A monitored technology channel publishes a video describing a new model.

FEXIS:

1. Detects the new video.
2. Retrieves available transcript and metadata.
3. Extracts capabilities, claims, pricing, limitations, and references.
4. Assesses evidence.
5. Compares the information against existing FDG knowledge.

If a relevant change is identified, FWAIS can initiate the appropriate review workflow.

The result may be:

**Knowledge Update Proposal**

rather than an uncontrolled automatic knowledge modification.
