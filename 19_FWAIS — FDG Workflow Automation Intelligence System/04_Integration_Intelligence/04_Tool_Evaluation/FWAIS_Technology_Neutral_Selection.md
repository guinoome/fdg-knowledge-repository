# FWAIS Technology-Neutral Capability Selection

## Selection order

Business outcome
→ Required capability
→ Existing FDG capability search
→ External capability research
→ Candidate mechanism comparison
→ Integration specification
→ Validation
→ Registration

## Candidate mechanisms

- Existing FDG connector
- API
- SDK
- MCP
- CLI
- Webhook
- Database integration
- File exchange
- Local service
- Remote service
- Custom adapter

## Evaluation criteria

Capability fit, evidence, security, reliability, maintainability, cost, performance, availability, complexity, lock-in, and replaceability.
