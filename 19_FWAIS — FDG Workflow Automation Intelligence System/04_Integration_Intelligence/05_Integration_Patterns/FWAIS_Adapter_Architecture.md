# FWAIS Adapter Architecture

Workflow
→ Required Capability
→ Capability Registry
→ Provider Selection
→ Adapter
→ Execution

The workflow should not depend directly on the provider whenever practical.

Provider changes should be handled at the adapter/capability layer rather than by redesigning the business workflow.
