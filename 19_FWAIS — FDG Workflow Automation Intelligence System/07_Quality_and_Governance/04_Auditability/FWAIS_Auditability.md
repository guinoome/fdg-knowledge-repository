# FWAIS Auditability

Record at minimum:

- Workflow version
- Trigger
- Input reference
- Processing path
- Tool/integration used
- Decisions made
- Human approvals
- Errors
- Recovery actions
- Output reference
- Timestamp
- Responsible identity

Do not store secrets in workflow documentation or audit logs.
