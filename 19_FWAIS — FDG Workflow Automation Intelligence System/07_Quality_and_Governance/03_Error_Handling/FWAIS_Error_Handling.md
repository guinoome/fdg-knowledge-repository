# FWAIS Error Handling

Every production workflow should define:

- Error detection
- Error classification
- Retry policy
- Idempotency
- Recovery action
- Escalation
- Alerting
- Error context
- Audit record
- Recovery verification

A separate error-handling workflow is appropriate where it improves reliability and observability.
