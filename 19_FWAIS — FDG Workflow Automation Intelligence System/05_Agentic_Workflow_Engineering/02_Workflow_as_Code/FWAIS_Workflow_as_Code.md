# FWAIS Workflow-as-Code / Reproducibility

Where practical, workflow definitions should be:

- Version controlled
- Reproducible
- Documented
- Testable
- Reviewable
- Deployable
- Rollback-capable

The repository should preserve workflow specifications separately from provider credentials and secrets.
