# FWAIS Agent Tool Selection

An agent should not receive unrestricted freedom to choose tools.

## Selection process

1. Identify required operation.
2. Check approved capabilities.
3. Check existing connectors.
4. Research alternatives when required.
5. Select the least-complex suitable mechanism.
6. Validate permissions and data boundaries.
7. Execute.
8. Validate output.
9. Record outcome.

Tool selection is a governed capability decision, not an uncontrolled model preference.
