# FWAIS Human-in-the-Loop Pattern

Automation handles routine, low-risk, well-defined cases.

Escalate when:

- Data is ambiguous
- Confidence is insufficient
- Business rule conflict exists
- Financial value exceeds an approval threshold
- Compliance risk is elevated
- Security boundary is crossed
- AI output affects an authoritative record
- A workflow failure cannot be safely recovered

Human review must receive complete context and the reason for escalation.
