# User, Usage & Subscription Intelligence

FPIS analyzes the relationship between users and platforms.

## User / Role Intelligence

Track, where legitimately available:

- user role
- platform access
- module usage
- workflow usage
- feature adoption
- errors
- friction
- requests
- feedback

## Subscription Intelligence

Track platform-level subscription evidence:

- subscriber count
- active subscribers
- trials
- new subscriptions
- renewals
- cancellations
- churn
- reactivation
- subscription tier
- usage by tier
- retention by tier
- value by tier

## Analysis

Examples:

- Which tier uses the platform most?
- Which tier has highest retention?
- Which capabilities drive upgrades?
- Which capabilities are ignored?
- Which subscription group generates the greatest platform value?
- What missing capability is repeatedly requested?

## Boundary

FPIS analyzes platform interaction and subscription evidence. It is not an HR surveillance system and is not the billing system of record.
