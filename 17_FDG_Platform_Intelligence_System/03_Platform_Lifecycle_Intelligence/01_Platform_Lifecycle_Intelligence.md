# Platform Lifecycle Intelligence

FPIS tracks the lifecycle state of every FDG platform.

## Lifecycle

Concept → Architecture → Prototype → Local Validation → Integration → Deployment → Operation → Evolution → Retirement

## Track

- current state
- entry criteria
- exit criteria
- blockers
- validation status
- release history
- deployment state
- operational state
- retirement conditions

## Principle

A platform should not advance to the next lifecycle stage merely because development is complete. Evidence and defined exit criteria are required.
