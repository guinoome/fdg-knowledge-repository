# Potential Enhancements Not Yet Fully Developed

The conversation identified or implied several valuable follow-on topics that should be developed without blocking the first deployment.

## FPIS / design governance
- formal Design Token Standard
- cross-module iconography library
- Experience Quality Assurance checklist
- accessibility/contrast validation standard
- motion-performance budget
- reduced-motion behavior
- screenshot/regression review process
- public-to-product conversion analytics
- experience telemetry that respects engineering/tenant privacy

## FEIS PM
- configurable PM template schema/versioning
- acceptance-rule library governance
- calibration/equipment-instrument register links
- defect/finding lifecycle across repeated PMs
- corrective action work-order integration
- evidence hashing/provenance
- report revision/digital signing architecture
- supervisor/engineer approval without blocking technician offline work
- local storage quota/attachment cleanup strategy
- encryption-at-rest strategy for offline device data
- lost/stolen-device access revocation
- tenant/project export/import package

## 3D / photo intelligence
- guided photo capture completeness scoring
- room-scale reference / dimensional calibration
- confidence visualization for inferred geometry
- equipment recognition confidence
- model correction UI
- verified-vs-inferred geometry layers

## Analytics / predictive maintenance
- trend analytics can start as historical/rule-based analysis
- predictive maintenance must wait for sufficient trustworthy historical data; do not label trend heuristics as trained prediction

## Business architecture
- reuse the offline field/evidence engine where business inspections or branch audits need the same capture/sync primitives
- connect Network Operations Layer with multi-branch inventory, fleet and alert patterns

## Commercialization
- tenant Experience Profiles and attribution rules should connect to [[FDG Commercial & Revenue Architecture]] before pricing/white-label tiers become canonical.
