# FDG Engineering Visual Language

## Protected semantic colors
- Green = Verified / Normal / Accepted
- Amber = Attention / Deviation / Pending
- Red = Failure / Critical Finding
- Blue = Measured / Actual Data
- Gray = Reference / Existing State
- Outline = Design / Expected State
- Pulse = Live / Changing State
- Dashed = Proposed / Simulated State

Client brand colors may style navigation, headers, buttons, imagery, and decorative accents. They must not corrupt these engineering meanings.

## Motion semantics
- flow animation → fluid / air / energy movement
- pulse → real-time measurement
- fade → inactive equipment
- red propagation → fault influence
- green propagation → successful commissioning sequence
- ghost geometry → design condition
- solid geometry → installed condition
- split view → before vs proposed
- exploded view → subsystem relationships
- timeline scrub → historical state
- heat surface → energy / thermal intensity
- particle flow → airflow / waterflow visualization

## Principle
Visual language is a form of engineering communication. Motion and color are functional signals, not decoration.
