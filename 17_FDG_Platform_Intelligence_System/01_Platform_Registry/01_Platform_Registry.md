# Platform Registry

The authoritative index of FDG platforms monitored by FPIS.

## Minimum Record

Each platform should have:

- Platform ID
- Platform name
- Purpose
- Owner
- Domain
- Current lifecycle state
- Current version
- Deployment state
- Primary users
- Subscription model
- Revenue/value status
- Technology stack
- Dependencies
- Current risks
- Current priorities
- Last validated state
- Linked source records

## Example

| Field | Example |
|---|---|
| Platform | FBPOIS |
| Domain | Building Plant Operations |
| Lifecycle | Local Validation |
| Deployment | Local-first |
| Users | Engineering roles |
| Subscription | TBD |
| Status | Active development |
| Roadmap | Local validation → integration |

## Rule

The registry points to source records; it should not duplicate detailed domain data unnecessarily.
