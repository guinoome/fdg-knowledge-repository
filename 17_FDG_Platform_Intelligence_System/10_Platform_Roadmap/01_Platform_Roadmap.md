# Platform Roadmap

FPIS maintains platform evolution roadmaps.

## Roadmap Dimensions

- capability
- architecture
- UX
- performance
- security dependency
- lifecycle
- subscription
- innovation
- technical debt
- retirement

## Priority Evidence

Prioritize based on:

Correctness → Risk → User Value → Business Value → Lifecycle Value → Engineering Effort

## Rule

Roadmap items should be traceable to evidence, decisions, or validated opportunities.
