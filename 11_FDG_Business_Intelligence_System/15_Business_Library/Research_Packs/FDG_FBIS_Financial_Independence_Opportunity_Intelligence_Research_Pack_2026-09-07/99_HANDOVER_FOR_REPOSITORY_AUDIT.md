# Mission

Integrate the approved financial-independence / owner-independent-value knowledge into the live FDG Knowledge Repository **without duplication, loss, or architectural drift**.

## Non-negotiable decisions

1. The book is a reference/inspiration source, not an authoritative financial standard.
2. The capability belongs inside FBIS; do not create another top-level intelligence system.
3. Canonical principle:
   > The FDG Ecosystem continues creating engineering, commercial, intellectual, and financial value even when its founder is not personally executing each transaction.
4. Personal/founder finances and FDG/business finances remain structurally separate.
5. "Passive income" is replaced as an engineering target by measurable owner-independent recurring value creation.
6. Safety-critical/professional engineering accountability remains human and qualified.
7. Every affected repository file must be logged in the change record.
8. Before an agent reaches its time/token limit, provide a concise handover with completed, changed, unresolved, evidence, and next actions.

1. Search all existing notes for financial independence, passive income, recurring revenue, founder dependency, opportunity intelligence, commercial/revenue architecture, capital allocation, productive assets, IP, subscriptions, and continuity.
2. Produce overlap/conflict report before edits.
3. Merge principles into existing canonical notes where possible.
4. Create only genuinely missing documents.
5. Update domain master indexes.
6. Add reciprocal ``[[Wikilinks]]``.
7. Preserve aliases if names change.
8. Run broken-link and duplicate-title checks.
9. Record exact files created/modified.
10. Do not overwrite existing approved architecture with this pack wholesale.

## Acceptance tests

Integration fails if:
- a parallel top-level system is created;
- book marketing claims are promoted to verified facts;
- personal and business finance data are commingled;
- any existing canonical index is silently replaced;
- new notes are isolated without backlinks;
- founder independence is defined as eliminating qualified human engineering review;
- a generated score cannot be traced to inputs and assumptions.
