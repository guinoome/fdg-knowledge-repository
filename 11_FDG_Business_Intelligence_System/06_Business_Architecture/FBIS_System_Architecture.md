# FBIS System Architecture

Commercial lifecycle:
Customer → Product/Service → Pricing → Order → Voucher/Discount → Payment → Validation → Fulfillment → Receipt → Refund/Cancellation → Settlement → Reconciliation → Revenue Intelligence.

Platform pattern:
FDG Platform → FBIS Commercial Interface → Reusable Business/Payment Service → External Provider.

Platforms must not become the authority for duplicated commercial rules.
