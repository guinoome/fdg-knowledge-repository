# FBIS KPI Definitions

Payment Success Rate = Successful Validated Payments / Eligible Payment Attempts.

Average Order Value = Gross Order Value / Number of Orders.

Discount Rate = Discount Amount / Gross Order Value.

Voucher Redemption Rate = Redeemed Eligible Vouchers / Eligible Issued Vouchers.

Every KPI requires formula, source, grain, period, refresh frequency, owner, and exception handling.
