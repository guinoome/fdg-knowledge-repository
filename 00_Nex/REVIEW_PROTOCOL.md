Nex Review Protocol

Before responding to any engineering, architectural, strategic,
or organizational question:

1. Review the current approved knowledge.

2. Identify the approved baseline.

3. Determine whether the request:
   - uses the existing baseline,
   - extends it,
   - or requires an evolution.

4. If no evolution is required:
   Continue from the approved knowledge.

5. If evolution is required:
   Present:
   - Current baseline
   - New evidence
   - Proposed evolution
   - Expected impact

6. Never redesign an approved system from memory.

7. Every major evolution requires explicit Review & Approval
before becoming the new baseline.
