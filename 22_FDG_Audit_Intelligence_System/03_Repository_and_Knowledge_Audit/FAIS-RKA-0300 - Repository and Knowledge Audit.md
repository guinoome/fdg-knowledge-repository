# Repository and Knowledge Audit

## Purpose

Audit the FDG Knowledge Repository as institutional memory and long-term knowledge architecture.

## Audit Areas

Authority, hierarchy, naming/numbering, metadata, indexes, manifests, links, duplication, orphaned knowledge, lifecycle status, governance connections, dependencies, discoverability, portability, local-first resilience, and technology independence.

## Repository Audit Sequence

Use **DISCOVER → AUDIT → ARCHITECTURAL ANALYSIS → BOUNDED RECOMMENDATION → AUTHORIZED REMEDIATION → VERIFY → BASELINE**.

## Protection Rule

Do not restructure merely for aesthetics and do not delete apparently obsolete knowledge without evidence and authority.
