# Audit Standards and Methodology

## Purpose

Provide a common method for planning, executing, documenting, reporting, and closing audits.

## Method

Define objective → scope → criteria → risks → evidence needs → sampling/test plan → fieldwork → evidence evaluation → findings → review → report → action tracking → verification → closure.

## Sampling

Sampling must be risk-based or otherwise justified. A sample result must not be represented as full-population assurance unless the method supports that conclusion.

## Working Papers

Working papers should make another competent reviewer able to understand what was tested, evidence examined, procedures performed, exceptions found, and basis for conclusions.
