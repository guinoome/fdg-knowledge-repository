# System and Software Audit

## Purpose

Audit software and information-system controls across requirements, architecture, implementation evidence, testing, deployment, and lifecycle.

## Audit Areas

Requirements traceability, architecture decisions, source/change control, dependencies, configuration, tests, defects, release evidence, data integrity, backup/recovery, security controls, observability, documentation, and rollback.

## No Premature Build

FAIS documentation does not authorize software construction. Automation follows validated manual workflows.

## Technology Independence

Assess lock-in, portability, stable data formats, replaceable interfaces, local operation, synchronization boundaries, and recoverability.

## Control Note

This document is part of the initial FAIS baseline. It may be expanded through controlled future milestones. Recommendations do not become FDG policy until approved through the applicable governance authority.
