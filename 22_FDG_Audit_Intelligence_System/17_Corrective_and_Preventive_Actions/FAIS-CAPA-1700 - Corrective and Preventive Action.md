# Corrective and Preventive Actions

## Purpose

Control the response to findings from containment through root cause, correction, corrective action, prevention, and effectiveness verification.

## CAPA Flow

Contain where necessary → determine cause → define correction → define corrective action → assign owner/date → implement → collect evidence → verify effectiveness → close or reopen.

## Root Cause Discipline

Avoid defaulting to 'human error' when process design, workload, training, tools, governance, communication, or control design contributed.

## Ownership

The audited domain owns remediation unless governance assigns otherwise. FAIS tracks and verifies rather than silently implementing changes.
